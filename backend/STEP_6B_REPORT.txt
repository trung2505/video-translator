## Task: synthesize_vietnamese_audio_task

**Location**: app/workers/tasks.py (lines 147-226)

**Responsibilities**:
1. Load all segments for the job
2. Extract translated_text from each segment
3. Concatenate with "\n" separator
4. Call LongTextTTS.synthesize_long_text(text, job_id, voice)
5. Receive final MP3 path
6. Create FileRecord(file_type='tts_audio', path=mp3_path)
7. Update job.output_file_id = file.id
8. Chain to subtitle_task
9. Handle errors (set FAILED, finished_at, error_message)
10. Re-raise exceptions to Celery

**Input**: 
- job_id (str): Job identifier
- Job must have completed translate_task (segments have translated_text)

**Output**:
- mp3_path (str): Path to final MP3 file
- FileRecord created with type='tts_audio'
- job.output_file_id updated

**Error Handling**:
- Catches LongTextTTSError specifically
- Catches generic Exception as fallback
- Sets job.status = FAILED
- Sets job.error_message with descriptive text
- Sets job.finished_at = datetime.utcnow()
- Re-raises to Celery (exception propagation)
- No fake MP3 files (LongTextTTS validates MP3 real magic bytes)
